# Logo 来源

以下 Logo 用于 README 致谢，归各自品牌所有，保留下载时的原始文件。`openai-rounded.svg` 嵌入原始 PNG，用圆角裁剪显示白色背景。

- `kimi.png`：[Kimi 官方品牌页面](https://www.kimi.com/resources/kimi-brand)引用的[品牌图标](https://statics.kimi.ai/kimi-web-seo/assets/kimi-logo-CegIMkbU.png)。
- `openai.png`：[OpenAI 官方 GitHub 组织](https://github.com/openai)的[头像](https://github.com/openai.png?size=128)。
- `volcengine.png`：[火山引擎官网](https://www.volcengine.com/)使用的[品牌图标](https://portal.volccdn.com/obj/volcfe/misc/favicon.png)。
- `datawhale.png`：[Datawhale 官方 GitHub 组织](https://github.com/datawhalechina)的[头像](https://github.com/datawhalechina.png?size=128)。

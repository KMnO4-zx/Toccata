# Toccata v0.0.2

正式开源前的体验版本，适用于 Apple Silicon Mac（macOS 13 或更新版本）。

- 键盘热力图显示所选时段使用次数最多的五个按键。
- 时间范围右侧新增分享入口，浮窗预览完整的活动图片。
- 分享图包含三项概览、键盘热力图、常用前五键、逐日时间线，以及前六个应用的图标、活跃时长与按键次数。
- 所有分享内容统一使用顶部选中的时间范围，以本机同一份已保存记录生成，避免不同页面的筛选互相干扰。
- 支持复制 PNG 图片到剪贴板，或选择保存目录（默认下载目录）；图片仅在本机生成。

将 DMG 中的 Toccata.app 拖到 Applications，替换旧版即可。任务和活动数据保留在原来的本机数据目录。此体验包采用 ad-hoc 签名，尚未执行 Apple 公证。

GitHub Release 仍需手动触发工作流；版本升级与本地打包不会自动发布。

# Toccata v0.0.8

正式开源前的体验版本，适用于 Apple Silicon Mac（macOS 13 或更新版本）。

- 状态栏任务浮窗切换排序时，任务会平滑移动到新的位置；顶部排序只调整主任务，子任务保留各自的顺序。
- 子任务右侧新增三条横线手柄。按住拖动时整行跟随鼠标，插入位置显示细线，松手后平滑落位并保存顺序。
- 拖动仅限同一主任务下、同一完成状态的子任务；未完成始终在上，已完成始终在下。拖出有效区域或按 Esc 取消，会回到原位。
- 子任务顺序保存到本机任务库，并在工作台、状态栏、日历、回顾和详情中同步；保留筛选中隐藏的子任务顺序，兼容已有任务数据。

将 DMG 中的 Toccata.app 拖到 Applications，替换旧版即可。任务和活动数据保留在原来的本机数据目录。此体验包采用 ad-hoc 签名，尚未执行 Apple 公证。

GitHub Release 仍需手动触发工作流；版本升级与本地打包不会自动发布。

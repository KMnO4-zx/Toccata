# Toccata v0.0.1

Toccata 的开发体验版本：一个 macOS 本地任务与键盘活跃工作台。正式开源首版计划使用 v0.1.0。

- 任务与收集箱支持主任务、子任务、Markdown 详情、计划日期和完成状态。
- 任务日历按创建、计划和完成日期查看记录；任务回顾支持自定义时段和复制周报素材。
- 菜单栏提供快捷任务列表、编辑浮窗、日历和工作台入口，关闭工作台后继续在后台运行。
- 键盘热力图、常用前三键、活跃时间线、活跃日历与应用统计按所选日期展示本机记录。
- 支持“月之亮面”“月之暗面”“跟随系统”，以及可选的登录时启动。
- 主界面侧栏可直接进入“关于 Toccata”，查看与复制版本信息，并手动检查 GitHub Releases 更新。

## 安装

支持 Apple Silicon Mac，macOS 13 或更新版本。下载 `Toccata-0.0.1-arm64.dmg`，将 Toccata 拖入“应用程序”。更新前先退出已运行的 Toccata，再替换应用；任务和活动数据保存在独立的本机数据目录中。

此包采用 ad-hoc 签名，尚未经过 Apple Developer ID 签名与公证，macOS 可能显示开发者验证提示。

任务功能无需键盘权限；键盘统计需用户自行在系统设置中允许输入监控。“登录时启动”默认关闭。更新检查只查询公开版本信息，不上传任务或键盘数据，也不会自动安装。

# Toccata v0.1.3

看清每个按键的使用占比，从菜单栏打开对应页面，任务筛选与切换也更连贯。

**2026-10-31 重发：v0.1.3 / build 21 替换原 build 20，补充应用内安装修复。已安装 v0.1.2 或 v0.1.3 build 20 的用户，请手动下载本页安装包并覆盖一次。**

## 更新内容

- **安装并重启修复**：修复下载完成后点击“安装并重启”，误报“请从已安装的 Toccata.app 中更新。”且未启动安装的问题。安装入口现在直接连接到应用生命周期，不再错误地转换 SwiftUI 的系统代理；继续先保存任务、停止后台记录，再启动安装器。
- **按键占比**：键盘热力图悬停提示新增当前所选时段的按键占比，以该时段总按键次数为基数，百分比最多保留 1 位小数。常用按键前五名、分享卡片及菜单栏活动速览同步显示占比；Fn 继续显示按住时长，并补充次数与占比。
- **工作台跳转**：在菜单栏小窗点击“工作台”，会根据当前页面打开对应的主界面：任务 → 任务，日历 → 任务日历，活动 → 键盘活跃。
- **任务切换交互**：任务范围、任务日历的记录筛选和显示方式、任务回顾范围统一使用主题色。选中背景平滑滑动，内容切换加入过渡动画；鼠标点击不再显示额外的外围焦点框，保留方向键操作，并适配系统“减少动态效果”设置。任务回顾的自定义时段在点击“应用”后更新，取消时保留原范围。
- **页面标题**：“应用与趋势”页补上标题与说明，让活跃日历和应用活跃度有统一的页面入口。

## 下载与安装

适用于 **Apple Silicon Mac · macOS 13+**。下载 `Toccata-0.1.3-arm64.dmg`，先退出旧版，再将 `Toccata.app` 拖入“应用程序”并替换。已有任务和活动数据保留在原来的本机数据目录。

**v0.1.2 和原 v0.1.3 build 20 的安装按钮存在上述问题，必须手动覆盖一次；v0.1.1 及更早版本也需手动升级。** 更新检查只比较版本号，因此原 v0.1.3 不会提示同为 v0.1.3 的 build 21。安装后可在“关于 Toccata”中复制版本信息，确认 Build 为 21。

安装 build 21 后，后续更高版本可通过“关于 Toccata → 检查更新”下载，再点击“安装并重启”。请从可写的应用程序目录运行，勿直接从只读 DMG 中更新。

- 使用 **macOS SDK 26.5** 构建，版本 **0.1.3 / build 21**。
- 安装包采用 ad-hoc 签名，尚未执行 Apple 公证。
- 同时提供 `.sha256` 文件，可运行 `shasum -a 256 -c Toccata-0.1.3-arm64.dmg.sha256` 校验。

## English

Toccata v0.1.3 adds key usage percentages, opens the matching workspace page from the menu bar, and refines task filters and transitions.

**Reissued on 2026-10-31: v0.1.3 / build 21 replaces build 20 with an in-app installation fix. Users on v0.1.2 or v0.1.3 build 20 must download this package and replace the app manually once.**

- **Install and restart fix**: fixes the incorrect “Update from an installed copy of Toccata.app.” message after downloading, which prevented the installer from starting. Installation now connects directly to the application's lifecycle instead of incorrectly casting SwiftUI's system delegate. Tasks are still saved and background recording stopped before the installer starts.
- **Key usage percentages**: keyboard heatmap tooltips show each key's share of all key presses in the selected period, rounded to at most one decimal place. Percentages also appear in the top five keys, share cards, and menu bar activity overview. Fn retains its hold duration and now includes its count and percentage.
- **Workspace navigation**: the menu bar's Workspace button opens the corresponding main page: Tasks → Tasks, Calendar → Task calendar, and Activity → Keyboard activity.
- **Task switching**: task periods, task calendar record and display filters, and review ranges use the theme accent color, with a sliding selection background and content transitions. Mouse clicks no longer show an extra outer focus border. Arrow-key navigation remains available, and transitions respect Reduce Motion. Custom review ranges take effect on Apply; cancelling preserves the previous range.
- **Page heading**: Apps & trends now has a title and description above its activity calendar and application activity sections.

For **Apple Silicon Macs running macOS 13 or later**. Download `Toccata-0.1.3-arm64.dmg`, quit the old app, and replace it with `Toccata.app` from the DMG. Existing local task and activity data are preserved.

**The installation button in v0.1.2 and the original v0.1.3 build 20 has this bug, so one manual replacement is required. Versions v0.1.1 and earlier also require a manual upgrade.** Update checks compare version numbers only, so the original v0.1.3 will not offer build 21 under the same version number. After installation, copy the version information from About Toccata and confirm Build is 21.

Once build 21 is installed, future higher versions can be downloaded from About Toccata and installed with Install and restart. Run the installed app from a writable location, not the read-only DMG.

Built with **macOS SDK 26.5**, version **0.1.3 / build 21**. The package is ad-hoc signed and has not been notarized by Apple. A SHA-256 checksum file is included.

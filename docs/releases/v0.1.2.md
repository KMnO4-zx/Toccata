# Toccata v0.1.2

在菜单栏就能看活动数据，常用设置集中到一页，后续更新也可以在应用内完成。

## 更新内容

- **通用配置**：工作台新增“设置 → 通用配置”，集中提供外观、界面语言、喝水提醒、登录时启动、Dock 图标和关于入口。左下角的外观、语言和关于入口继续保留，选项浮窗样式统一。登录自启默认关闭，Dock 图标默认显示，可按需隐藏。
- **菜单栏活动速览**：无需打开工作台，即可查看今日或昨日的键盘与应用活动。键盘页提供热力图和每格 15 分钟的活跃时段，悬停查看详细数据；内容固定展示，无需上下滚动。应用页列出全部应用的活跃时长和按键次数，支持滚动查看。切换键盘、应用及日期时加入过渡动画，并遵循系统“减少动态效果”设置。
- **状态栏默认页面**：可在通用配置中选择“任务管理”“任务日历”或“活动速览”，默认任务管理。每次打开菜单栏小窗都会使用所选页面。
- **应用内更新**：在“关于 Toccata”中检查并下载新版，支持进度显示、取消和重试。下载后校验安装包，点击“安装并重启”会先保存任务和键盘记录，再替换应用并重新打开；替换或启动命令失败时尝试恢复原应用。没有兼容安装包时保留发布页入口。

应用更新由用户在关于页触发，不会在后台定时检查或自行重启。更新只替换应用，不替换本机任务和活动数据。

## 下载与安装

适用于 **Apple Silicon Mac · macOS 13+**。下载 `Toccata-0.1.2-arm64.dmg`，先退出旧版，再将 `Toccata.app` 拖入“应用程序”并替换。已有任务和活动数据保留在原来的本机数据目录。

**v0.1.1 及更早版本需要手动升级一次。安装 v0.1.2 后，后续兼容版本可在应用内下载并安装。** 请从可写的应用程序目录运行，勿直接从只读 DMG 中更新。

- 使用 **macOS SDK 26.5** 构建，版本 **0.1.2 / build 19**。
- 安装包采用 ad-hoc 签名，尚未执行 Apple 公证。
- 同时提供 `.sha256` 文件，可运行 `shasum -a 256 -c Toccata-0.1.2-arm64.dmg.sha256` 校验。

## English

Toccata v0.1.2 brings activity summaries to the menu bar, gathers preferences in General settings, and adds in-app updates.

- **General settings**: appearance, language, water reminders, launch at login, Dock visibility, and About are available in one place. The existing sidebar shortcuts remain, with consistent selection popovers. Launch at login is off by default; the Dock icon is shown by default and can be hidden.
- **Activity overview**: view today's or yesterday's keyboard and application activity without opening the workspace. The keyboard page includes a heatmap and a 15-minute activity timeline with hover details, fitting without vertical scrolling. The application page lists activity time and key counts for every app and scrolls as needed. Tab and date changes have transitions that respect Reduce Motion.
- **Default menu bar page**: choose Task management, Task calendar, or Activity overview in General settings. Each opening uses that preference; Task management is the default.
- **In-app updates**: check for and download releases from About Toccata, with progress, cancellation, and retry. Packages are verified before installation. Install and restart saves tasks and keyboard records before replacing and reopening the app, with recovery attempted if replacement or the launch command fails. The release page remains available when no compatible package exists.

Updates are user initiated; there are no scheduled background checks or automatic restarts. Only the app is replaced, leaving local task and activity data in place.

For **Apple Silicon Macs running macOS 13 or later**. Quit the old app and replace it with `Toccata.app` from the DMG. **Versions v0.1.1 and earlier require this one manual upgrade; v0.1.2 can download and install future compatible releases from About.** Run the installed app from a writable location, not the read-only DMG.

Built with **macOS SDK 26.5**, version **0.1.2 / build 19**. The package is ad-hoc signed and has not been notarized by Apple. A SHA-256 checksum file is included.

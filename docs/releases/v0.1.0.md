# Toccata v0.1.0

记下想法，看见投入。Toccata 的第一个里程碑版本，把 ToDo 管理、每周回顾与键盘活跃记录放在一个 macOS 应用里。

## 功能

- **ToDo 管理**：主界面与菜单栏小窗，快速记录任务、拆分子任务、用 Markdown 写详情，并通过任务日历安排日期。
- **每周回顾**：汇总本周完成与尚未完成的任务，一键复制为周报素材。
- **键盘活跃**：逐键热力图、实时按键反馈、按天活跃时间线、应用排行与统计分享图片。
- **思维净活跃时长**：用键盘活动估算主动输出的时间，单独查看 Fn 按住时长。这个概念无法直接测量思维，也无法覆盖阅读、思考等全部投入。
- **本机记录**：任务与键盘活动保存在本机，采集过程不截图、不录音；任务管理可以独立使用。
- **外观与语言**：支持浅色、深色、中英文切换与减少动态效果。

## 下载与安装

适用于 **Apple Silicon Mac · macOS 13+**。下载 `Toccata-0.1.0-arm64.dmg`，将 `Toccata.app` 拖入“应用程序”后打开。

- 键盘记录需要在“系统设置 → 隐私与安全性 → 输入监控”中授权。
- 从旧版本升级时，替换 App 即可，任务和活动数据保留在原来的本机数据目录。
- 此安装包采用 ad-hoc 签名，尚未执行 Apple 公证。
- 同时提供 `.sha256` 文件，下载后可在文件所在目录运行 `shasum -a 256 -c Toccata-0.1.0-arm64.dmg.sha256` 校验。

## English

Capture ideas. See your effort. Toccata v0.1.0 brings together to-do management, weekly reviews, and keyboard activity tracking on macOS.

- Manage tasks and subtasks in the main workspace or menu bar window, write Markdown details, and plan dates with the task calendar.
- Review completed and unfinished tasks, then copy them for your weekly report.
- Explore per-key heatmaps, live key feedback, daily activity timelines, app rankings, and shareable statistics.
- Estimate “net active thinking time” from keyboard activity, with Fn hold time shown separately. This is a creative concept and an estimate, not a direct measurement of thought or all mental effort.
- Keep task and keyboard activity records on your Mac. Capture takes no screenshots and records no audio.
- Read the new bilingual README and developer guide, with demo screenshots and documented counting rules.

For **Apple Silicon Macs running macOS 13 or later**. Download the DMG and drag `Toccata.app` into Applications. Grant Input Monitoring permission to enable keyboard tracking; task management works independently. Replacing an older app preserves existing local data.

The package is ad-hoc signed and has not been notarized by Apple. A SHA-256 checksum file is included for verification.

# Toccata v0.0.11

正式开源前的体验版本，适用于 Apple Silicon Mac（macOS 13 或更新版本）。

- 活跃时间线增加每日按键次数，显示在 Fn 按住时长左侧；分享图片同步显示每日按键次数，并适配中英文排版。
- 工作台侧栏的选中背景加入平滑滑移动画，跨分组切换和连续点击时跟随最新选择；开启系统“减少动态效果”时改为淡入淡出。保留上下方向键导航与编辑框的正常键盘操作。

将 DMG 中的 Toccata.app 拖到 Applications，替换旧版即可。任务和活动数据保留在原来的本机数据目录。此体验包采用 ad-hoc 签名，尚未执行 Apple 公证。

GitHub Release 仍需手动触发工作流；版本升级与本地打包不会自动发布。

# Toccata v0.1.1

菜单栏常驻，少占一个 Dock 位置；敲了一阵键盘，也记得喝口水。

## 更新内容

- **隐藏 Dock 图标**：打开工作台时也不占用 Dock。关闭工作台后继续在后台运行，从菜单栏可添加和管理任务、重新打开工作台；选择“退出 Toccata”结束应用。
- **喝水提醒**：右键菜单栏图标，选择“喝水提醒…”即可开启。默认每累计 **8,192 次按键**发送一次本地通知，可调整为 4,096、8,192、16,384 或 32,768 次，并提供“发送测试通知”。
- **每天重新计数**：与键盘活跃页使用相同的今日累计按键口径，合并实时和已保存记录。重启不会重复提醒，跨过多个提醒点只发送最近一次；开启提醒或调整间隔后从下一个提醒点开始。

喝水提醒默认关闭，首次开启需单独允许通知。计数沿用键盘记录，需要输入监控权限；关闭工作台后仍可提醒，退出 Toccata 后停止。系统通知设置和专注模式可能影响通知显示。

## 下载与安装

适用于 **Apple Silicon Mac · macOS 13+**。下载 `Toccata-0.1.1-arm64.dmg`，将 `Toccata.app` 拖入“应用程序”后打开。升级前先退出旧版，再替换 App；任务和活动数据保留在原来的本机数据目录。

- 使用 **macOS SDK 26.5** 构建，版本 **0.1.1 / build 18**。
- 安装包采用 ad-hoc 签名，尚未执行 Apple 公证。
- 同时提供 `.sha256` 文件，可运行 `shasum -a 256 -c Toccata-0.1.1-arm64.dmg.sha256` 校验。

## English

Toccata v0.1.1 keeps the workspace and task controls available from the menu bar without a Dock icon, and adds optional water reminders based on keyboard activity.

- **No Dock icon**: open or close the workspace while Toccata continues running in the menu bar. Task management stays available; choose **Quit Toccata** to stop the app.
- **Water reminders**: right-click the menu bar icon and choose **Water reminders…**. The default interval is **8,192 key presses**, with options for 4,096, 8,192, 16,384 or 32,768 presses and a test notification button.
- **Daily counts without duplicate reminders**: counts match the keyboard activity view and combine live and saved events. Restarting does not replay handled milestones. Catching up across several milestones sends only the latest reminder; enabling reminders or changing the interval starts at the next milestone.

Reminders are off by default and require separate notification permission. Key counts use the existing Input Monitoring records. Reminders continue with the workspace closed and stop when you quit Toccata. Focus and system notification settings may affect their presentation.

For **Apple Silicon Macs running macOS 13 or later**. Quit the previous app before replacing it; existing local task and activity data are preserved. Built with **macOS SDK 26.5**, version **0.1.1 / build 18**. The package is ad-hoc signed and has not been notarized by Apple. A SHA-256 checksum file is included.

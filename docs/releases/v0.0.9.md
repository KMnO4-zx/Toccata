# Toccata v0.0.9

正式开源前的体验版本，适用于 Apple Silicon Mac（macOS 13 或更新版本）。

- 新增简体中文与 English 界面，可在主界面侧栏或应用设置中切换，选择自动保存。首次启动按系统首选语言选择中文或英文，其他系统语言默认英文。
- 工作台、状态栏任务浮窗、日期选择、关于页与分享图同步切换语言；任务标题和描述保留用户原文。
- 侧栏语言选择使用与外观一致的浮窗，当前选项带有高亮和勾选。切换语言时加入轻微淡出、淡入，保留当前任务、筛选范围和编辑草稿，并遵循系统的减少动态效果设置。
- 活跃时间线新增最近 7 天、本周和自定义时段，保留跟随范围、今日和昨日。自定义时段可选择单日或连续多日。

将 DMG 中的 Toccata.app 拖到 Applications，替换旧版即可。任务和活动数据保留在原来的本机数据目录。此体验包采用 ad-hoc 签名，尚未执行 Apple 公证。

GitHub Release 仍需手动触发工作流；版本升级与本地打包不会自动发布。

# Toccata v0.1.4

主任务可以整组拖拽、置顶，菜单栏与工作台共用任务排序。

## 更新内容

- **主任务整组拖拽**：菜单栏和工作台都可拖动主任务，子任务一起移动。拖拽手柄更大，放置判定覆盖整组区域及相邻空隙；收紧列表右侧留白，为任务标题留出更多空间。成功拖动主任务后切换为手动排序，保留其他任务的相对顺序。
- **任务置顶**：通过任务详情中的图钉按钮或右键菜单置顶、取消置顶。对子任务操作会作用于所属主任务，整组一起调整位置；移动使用平滑动画，并遵循系统“减少动态效果”设置。
- **统一排序**：两处列表共享并保存排序设置，支持手动、创建时间从新到旧、创建时间从旧到新、任务名称、计划时间从早到晚。未设置计划日期的任务排在后面；未完成与已完成仍分开显示，各组内置顶任务在前。
- **简化优先状态**：移除高、中、低优先级，仅保留默认与置顶。已有优先级不会自动变为置顶，任务内容、日期和子任务关系保留。

## 下载与安装

适用于 **Apple Silicon Mac · macOS 13+**。版本 **0.1.4 / build 22**，使用 **macOS SDK 26.5** 构建。

下载 `Toccata-0.1.4-arm64.dmg`，退出旧版后将 `Toccata.app` 拖入“应用程序”并替换。已有任务和活动数据保留在原来的本机数据目录。

- v0.1.3 build 21 支持通过“关于 Toccata → 检查更新”下载新版，再点击“安装并重启”。
- v0.1.2、原 v0.1.3 build 20 及更早版本需手动覆盖安装一次。请从可写的应用程序目录运行，勿直接从只读 DMG 中更新。
- 安装包采用 ad-hoc 签名，尚未执行 Apple 公证。
- 提供 `.sha256` 文件，可运行 `shasum -a 256 -c Toccata-0.1.4-arm64.dmg.sha256` 校验。

## English

Toccata v0.1.4 adds whole-task dragging and pinning, with shared task sorting in the menu bar and main workspace.

- **Drag whole task groups**: move a main task with its subtasks in either list. Larger handles and more forgiving drop areas accept the full task group and nearby gaps. Tighter right spacing leaves more room for task titles. A successful root-task move switches to manual order while preserving the relative order of other tasks.
- **Pin tasks**: pin or unpin from the detail pane or context menu. Actions on a subtask apply to its parent group. Position changes animate smoothly and respect Reduce Motion.
- **Shared sorting**: both lists remember the same choice: manual order, newest first, oldest first, task name, or earliest planned date. Tasks without a planned date come last. Pending and completed groups remain separate, with pinned tasks first in each group.
- **Simpler priority states**: high, medium, and low priorities are removed. Tasks are either pinned or default. Previous priorities do not become pins; task content, dates, and parent-child relationships are preserved.

For **Apple Silicon Macs running macOS 13 or later**. Built with **macOS SDK 26.5**, version **0.1.4 / build 22**.

Download `Toccata-0.1.4-arm64.dmg`, quit the old app, and replace it in Applications. Existing local task and activity data are preserved. Users on v0.1.3 build 21 can use About Toccata → Check for Updates → Install and restart. Users on v0.1.2, the original v0.1.3 build 20, or earlier versions must replace the app manually once. Run the installed app from a writable location, not the read-only DMG.

The package is ad-hoc signed and has not been notarized by Apple. A SHA-256 checksum file is included.

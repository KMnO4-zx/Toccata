# Toccata v0.0.3

正式开源前的体验版本，适用于 Apple Silicon Mac（macOS 13 或更新版本）。

- 补充妙控键盘 F1–F12 的原始按键及亮度、媒体等顶部功能事件采集，并与普通键盘事件去重。
- 修正 Lock 的键码映射；锁屏点击不把锁屏期间记为持续按住。
- 修复 Caps Lock 关闭时漏计、将大写锁定状态误计为长按的问题。
- 分享图改用更紧凑的纵向排版，减少留白，放大统计、常用按键与应用信息，方便在手机上查看。

将 DMG 中的 Toccata.app 拖到 Applications，替换旧版即可。任务和活动数据保留在原来的本机数据目录；旧版本漏记的按键无法补回。此体验包采用 ad-hoc 签名，尚未执行 Apple 公证。

GitHub Release 仍需手动触发工作流；版本升级与本地打包不会自动发布。

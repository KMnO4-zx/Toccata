# Toccata v0.0.10

正式开源前的体验版本，适用于 Apple Silicon Mac（macOS 13 或更新版本）。

- 新增按天统计缓存，复用历史键盘活跃、按键次数和应用排行汇总，减少重复扫描与计算。新增记录会增量处理，当天及受实时按键影响的日期继续现算；缓存可重建，不会删除或压缩原始记录。
- 键盘热力图新增实时按键高亮、计数气泡和长按时长反馈；离开页面后停止动效订阅。去掉键盘活跃页未处理按键的系统提示音，保留正常快捷键、按键统计和动效。
- 主界面与状态栏的任务输入、详情和子任务输入增加悬停与聚焦反馈；任务和子任务可点击加号或按回车添加，空白内容不可提交。
- 切换任务时，右侧详情加入短暂过渡动画，并遵循系统的减少动态效果设置。
- 修复主任务从待办移到已完成分组后，勾选状态和标题样式未及时更新的问题。
- 修复展开子任务时可能导致窗口无响应的列表布局问题，同步调整日历中的相关布局；后台订阅连接增加写入超时，避免停止读取的客户端持续阻塞事件广播。
- 固定主界面任务日历的滚动条预留空间，切换任务数量不同的日期时保持日历宽度稳定；状态栏任务日历改用更细、更浅的滚动条。
- 任务列表的显示方式改为紧凑的上方展开浮窗，样式与语言、外观选择保持一致。
- 关于页同时显示应用版本和构建时的 Git Commit，并可复制版本信息；新增「去点 Star 🌟」入口，英文文案同步更新。

本次性能改进集中在历史统计缓存和已定位的阻塞问题，尚未加入滚动帧率优化。

将 DMG 中的 Toccata.app 拖到 Applications，替换旧版即可。任务和活动数据保留在原来的本机数据目录。此体验包采用 ad-hoc 签名，尚未执行 Apple 公证。

GitHub Release 仍需手动触发工作流；版本升级与本地打包不会自动发布。
